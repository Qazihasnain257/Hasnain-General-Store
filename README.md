# Hasnain General Store

A modern and responsive e-commerce website for a general store, built with React and Vite.

## Features

- Product browsing
- Product search
- Category filtering
- Product sorting
- Product variants and sizes
- Shopping cart
- Checkout
- Printable receipts
- Dark mode
- Responsive design
- Modern user interface

## Products

The store includes products such as:

- Snacks
- Drinks
- Milk
- Juice
- Gum
- Soap
- Washing Powder
- Shampoo
- Jellies
- Nimkos
- Household and personal-care products

## Tech Stack

- React
- Vite
- JavaScript
- HTML
- CSS
